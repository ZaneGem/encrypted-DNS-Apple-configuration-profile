# encrypted-DNS-Apple-configuration-profile
加密dns用处：隐藏dns查询记录 可用于防止运营商及路由器的记录、窃取及修改，隐藏访问目标，只有你和你的加密dns服务商知道你访问了什么
（中国大陆dns服务商公司受法律法规约束，必须向上级部门披露访问记录）

我从2024年中开始研究如何在苹果设备上部署加密dns配置文件，在时代的进程中，逐渐地发现从前配置好的境外加密dns服务已在中国大陆防火墙的逐渐演化中阻断致失效，在2026年末的当下，仅有极个别境外dns服务商及大陆公司的服务能够正常使用，本仓库中即是能部署在苹果设备上的加密dns系统配置文件（未签名但无风险）
